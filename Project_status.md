
# OSAI - Project Development Status

## Project Overview

OSAI (Oil Spill Attribution Intelligence) is an
AI-powered satellite intelligence project designed
to detect marine oil spills, estimate their
geographical extent, and support potential vessel
attribution using historical AIS data.

## Development Philosophy

OSAI is being developed incrementally, with
satellite-based detection and segmentation as
the foundation for subsequent geospatial,
temporal, and vessel attribution modules.

Database integration and complete application
deployment are planned future developments.
